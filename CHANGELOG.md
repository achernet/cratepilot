# Release notes

## 0.2.0 — Discovery, acquisition review, and smart crates

- Added a versioned canonical catalog, provenance edges, resumable discovery sessions, acquisition records, local preferences, and smart crates with a migration from database version 1.
- Added local, public Spotify URL, and manual seeds; bounded two-hop graph expansion; deterministic YouTube version ranking; duplicate collapse; and strict 1–30 draft readiness.
- Added safe legal-source links and an explicit, locally acknowledged acquisition pipeline with immutable sources, 320 kbps derivatives, 11 × 12-second consensus verification, quarantine, and MusicBrainz year evidence.
- Added `discover`, `acquire`, `catalog`, and `crate` CLI workflows plus matching token-protected local APIs and managed audio streaming.
- Added the guided private browser workflow, interactive public discovery fixture, smart-crate review, full-screen signal visualizers, v2 case-study material, and provider-free public build boundary.
- Added v2 identity, graph, ranking, migration, acknowledgement, smart-crate, readiness, API, and security tests.

## 0.1.0 — Recruiter demo and first-booth foundation

- Extracted the proven DJ analysis, rendering, and transition-learning engine without the private .djlearn workspace.
- Added stable V1 track, transition, set, and export models with SQLite persistence.
- Replaced greedy ordering with deterministic bounded beam search returning three ranked drafts.
- Added a localhost-only FastAPI job service, session token, origin/host checks, and library-root path validation.
- Added the one-command packaged browser interface and non-destructive Rekordbox staging export.
- Added the interactive public planner, Web Audio transition approximation, engineering case study, accessibility/responsive states, credits, and social metadata.
- Added Python/TypeScript golden scorer fixtures, product-specific tests, CI, architecture notes, and the Windows first-booth guide.

Known release boundary: public 0.1 uses synthesized auditions. It does not redistribute CC BY source recordings; real adapted excerpts require a separate manual audio review and checksum manifest.
