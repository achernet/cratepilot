# Release notes

## 0.1.0 — Recruiter demo and first-booth foundation

- Extracted the proven DJ analysis, rendering, and transition-learning engine without the private .djlearn workspace.
- Added stable V1 track, transition, set, and export models with SQLite persistence.
- Replaced greedy ordering with deterministic bounded beam search returning three ranked drafts.
- Added a localhost-only FastAPI job service, session token, origin/host checks, and library-root path validation.
- Added the one-command packaged browser interface and non-destructive Rekordbox staging export.
- Added the interactive public planner, Web Audio transition approximation, engineering case study, accessibility/responsive states, credits, and social metadata.
- Added Python/TypeScript golden scorer fixtures, product-specific tests, CI, architecture notes, and the Windows first-booth guide.

Known release boundary: public 0.1 uses synthesized auditions. It does not redistribute CC BY source recordings; real adapted excerpts require a separate manual audio review and checksum manifest.
